# Diagramas Estructurales

Los diagramas estructurales modelan los **aspectos estáticos** del sistema: las clases del dominio, las instancias, los componentes de software, la infraestructura de despliegue y la organización del código.

## Diagramas incluidos

| Tipo | Archivo | Descripción |
|------|---------|-------------|
| **Clases** | `1-Clases/diagrama-clases.puml` | Modelo de dominio completo con clases, atributos, métodos y relaciones |
| **Objetos** | `2-Objetos/diagrama-objetos.puml` | Instancias concretas del modelo de dominio |
| **Componentes** | `3-Componentes/diagrama-componentes.puml` | Organización de componentes de software y sus dependencias |
| **Despliegue** | `4-Despliegue/diagrama-despliegue.puml` | Infraestructura física y despliegue del sistema |
| **Paquetes** | `5-Paquetes/diagrama-paquetes.puml` | Organización del código fuente en paquetes |
| **Perfil** | `6-Perfil/diagrama-perfil.puml` | Estereotipos, enumeraciones y perfiles UML del sistema |
