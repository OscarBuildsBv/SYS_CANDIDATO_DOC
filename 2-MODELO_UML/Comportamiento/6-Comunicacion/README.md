# Diagramas de Comunicación

Los diagramas de comunicación muestran el **intercambio de mensajes** entre los objetos/componentes del sistema, numerados en orden secuencial.

## Módulos

| Archivo | Módulo |
|---------|--------|
| `Comunicacion-area_cliente.puml` | Área Cliente |
| `Comunicacion-citas.puml` | Sistema de Citas |
| `Comunicacion-consulta.puml` | Consulta Legal |
| `Comunicacion-gestionar-perfil.puml` | Gestionar Perfil |
| `comunicacion-publicacion.puml` | Publicaciones |
| `Comunicacion-servicio_legales.puml` | Servicios Legales |
