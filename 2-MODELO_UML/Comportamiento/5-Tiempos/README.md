# Diagramas de Tiempo

Los diagramas de tiempo muestran los **cambios de estado** de los actores y el sistema a lo largo del tiempo, permitiendo visualizar restricciones temporales.

## Módulos

| Archivo | Módulo |
|---------|--------|
| `Tiempo-area_cliente.puml` | Área Cliente |
| `Tiempo-citas.puml` | Sistema de Citas |
| `Tiempo-consulta.puml` | Consulta Legal |
| `Tiempo-gestionar-perfil.puml` | Gestionar Perfil |
| `Tiempo-publicacion.puml` | Publicaciones |
| `Tiempo-servicio_legales.puml` | Servicios Legales |
