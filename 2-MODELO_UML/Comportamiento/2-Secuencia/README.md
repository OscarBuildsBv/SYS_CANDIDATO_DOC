# Diagramas de Secuencia

Los diagramas de secuencia muestran la **interacción temporal** entre los actores y los componentes del sistema para cada funcionalidad.

## Módulos

| Archivo | Módulo | Descripción |
|---------|--------|-------------|
| `secuencia-area_cliente.puml` | Área Cliente | Login, consulta de caso, subida de documentos, comunicación con abogado |
| `secuencia-citas.puml` | Citas | Agendamiento de cita desde el portal |
| `secuencia-consultas.puml` | Consultas | Registro de consulta legal |
| `secuencia-gestionar-perfil.puml` | Gestionar Perfil | Visualizar/editar perfil, cambiar contraseña, actualizar foto, admin usuarios |
| `secuencia-publicacion.puml` | Publicaciones | Crear y publicar contenido |
| `secuencia-servicio_legales.puml` | Servicios Legales | Solicitud de cita y gestión administrativa |
