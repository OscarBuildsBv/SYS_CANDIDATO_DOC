# Diagramas de Actividades

Los diagramas de actividades modelan el **flujo de trabajo** o proceso de negocio de cada módulo, mostrando la secuencia de pasos y las decisiones.

## Módulos

| Archivo | Módulo |
|---------|--------|
| `Actividad-area_cliente.puml` | Área Cliente |
| `Actividad-citas.puml` | Sistema de Citas |
| `Actividad-consultas.puml` | Consulta Legal |
| `Actividad-gestionar-perfil.puml` | Gestionar Perfil |
| `Actividad-publicacion.puml` | Publicaciones |
| `Actividad-servicio_legales.puml` | Servicios Legales |
