# Modelo UML - Sistema de Gestión Legal

Esta carpeta contiene los **diagramas UML** del sistema, organizados en dos grandes categorías: **Comportamiento** (diagramas dinámicos) y **Estructural** (diagramas estáticos).

## Estructura

```
2-MODELO_UML/
├── Comportamiento/         # Diagramas de comportamiento (dinámicos)
│   ├── 1-Casos_Uso/        # Casos de uso por módulo
│   ├── 2-Secuencia/        # Diagramas de secuencia
│   ├── 3-Actividades/      # Diagramas de actividades
│   ├── 4-Estado/           # Diagramas de estados
│   ├── 5-Tiempos/          # Diagramas de tiempo
│   └── 6-Comunicacion/     # Diagramas de comunicación
└── Estructural/            # Diagramas estructurales (estáticos)
    ├── 1-Clases/           # Diagrama de clases
    ├── 2-Objetos/          # Diagrama de objetos
    ├── 3-Componentes/      # Diagrama de componentes
    ├── 4-Despliegue/       # Diagrama de despliegue
    ├── 5-Paquetes/         # Diagrama de paquetes
    └── 6-Perfil/           # Diagrama de perfil
```
