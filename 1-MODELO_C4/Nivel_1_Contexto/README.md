# Nivel 1 - Diagrama de Contexto

Muestra la visión general del sistema, los usuarios que interactúan con él y los sistemas externos con los que se integra.

## Actores identificados

- **Cliente**: Usuario registrado que solicita servicios legales, agenda citas y consulta casos
- **Abogado**: Profesional legal que atiende casos y crea publicaciones
- **Administrador**: Encargado de gestionar usuarios y contenido del sistema
- **Visitante**: Usuario no registrado que consulta información pública

## Sistemas externos

- **Servicio SMS**: Gateway para notificaciones por mensaje de texto
- **Servicio Email**: Servidor SMTP para comunicaciones por correo electrónico
